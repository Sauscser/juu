Country administrative boundaries loaded on demand
Source: geoBoundaries geoBoundaries Open data API
Availability metadata:
https://www.geoboundaries.org/api/current/gbOpen/{ISO3}/ALL/
Selected-level metadata:
https://www.geoboundaries.org/api/current/gbOpen/{ISO3}/{ADM}/
Geometry is retrieved from the CORS-enabled GitHub media host referenced by
the selected-level metadata. Country and administrative-level availability
varies. Each level's canonical administrative name and license are shown in
the picker. Geometry is fetched only after the user selects a level; no paid
map service or application-side proxy is used.
